# Production Topic Label Review

Read-only production review of current Turso BERTopic labels on 2026-06-28.

Scope: semantic topics `0` through `45`. Topic `-1` is `Uncategorized` and was not treated as a label-quality issue.

Review basis: current `topics.label`, `topics.top_terms`, `document_topics`, and constituent document titles/abstract snippets from production Turso. Judgments below use a librarian-style coverage test: a label should describe the cluster as a whole, avoid overfitting a single document, and avoid implying specificity not supported by the constituent documents.

Status key:

- `Keep`: label is acceptable as the public label.
- `Revise`: improved label recommended.
- `Review/Split`: proposed label is better, but the cluster itself is mixed enough that admin review or reclustering/merge-split work is recommended.

## Highest Priority Revisions

The labels most likely to mislead users are topics `17`, `18`, `20`, `30`, `31`, `34`, `37`, and `43`. These either overfit one document title or combine unrelated terms into a fluent but misleading phrase.

## Process Recommendation

Use these recommended labels as admin-reviewed candidates, not silent automatic replacements. Several clusters are mixed enough that the better label is only a pragmatic public label; reclustering, merging, or splitting would improve the underlying topic model more than wording alone.
